Why is PaymentLedger isolated into its own model instead of just adding a `paid_at` timestamp on Orders?

neurology
Architectural Rationale

Separating PaymentLedger from mutable Orders prevents high-frequency read/write row contention and enforces financial audit compliance through append-only immutability.

verifiedpackages/models/ledger.py:24
class PaymentLedger(BaseModel):
    id: UUID = Field(default_factory=uuid4)
    order_id: UUID = Field(foreign_key="orders.id")
    amount_cents: int
    tamper_hash: str  # HMAC-SHA256
    
    class Config:
        frozen = True  # Enforces append-only
shield_with_heart

Security Guarantee: If an Order transitions between PENDING, DISPATCHED, or REFUNDED, the immutable ledger entry remains cryptographically intact without trigger cascades.
