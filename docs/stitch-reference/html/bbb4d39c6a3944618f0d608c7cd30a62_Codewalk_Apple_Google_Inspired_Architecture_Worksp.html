Design Intent & Isolation RFC #104

Why isolate PaymentLedger from Orders?

Separating PaymentLedger from mutable Orders mitigates row contention during concurrent status updates and satisfies SOC2 audit requirements via append-only immutability.

Transactional Guarantee

When an Order transitions through state changes (PENDING → PAID → FULFILLED), prior financial ledger rows are never updated in-place. Compensating ledger transactions are created instead.
